# PortalV: SA picture inside GTA V Enhanced

`PortalV.asi` has two jobs in Story Mode: the Script Hook V script publishes the final rendered GTA camera state and owns the persistent portal calibration; its ReShade add-on reads the latest GTA SA offscreen-camera frame from PortalDev and draws it on a clipped world plane with GTA depth occlusion. WGC remains a fallback when the SA offscreen stream is unavailable.

## Build and deploy

Build `src/PortalV/PortalV.vcxproj` and `src/PortalDev/PortalDev.vcxproj` as Release x64, or use `src/Build-Dev.ps1`. PortalDev's **部署 V + FX** copies `PortalV.asi` and `src/PortalV/shaders/PortalSA.fx` into the selected GTA V Enhanced installation. Use a dedicated Story Mode development installation; do not deploy to the installation used for GTA Online. The game must be closed before deployment. The app does not copy the game or overwrite a ReShade preset.

The game needs Script Hook V, an ASI loader, and an add-on capable ReShade D3D12 runtime. The pinned ReShade source and official full add-on download are version 6.8.0 as checked on 2026-10-09: https://reshade.me/. `ReShade64.asi` plus `ReShade.fxh` in `reshade-shaders/Shaders` is the reference project's Enhanced setup; a working D3D12 ReShade installation is also suitable. PortalDev reports whether it detects a runtime, but the ReShade overlay/log is the actual loading check. In ReShade, enable the `PortalSA` technique from `PortalSA.fx`, and choose the GTA scene depth buffer if ReShade does not select it automatically. Do not replace an existing user's preset just to enable this technique.

## Place and test the picture

Run PortalDev, then start SA and GTA V Story Mode. With GTA V in the foreground, press **F9 once** to place and immediately save an 8 m diameter circle at the current player's feet, facing the player's heading; its bottom 0.6 m is below the ground. F9 no longer opens ReShade, so character control is never captured. Press **F8** whenever you want to reopen the `GTAPortal Calibration` panel. Every radius, height, feather, and crop adjustment is applied live and saved immediately; `Lock In` remains as an explicit save button but no longer ends the editing session. Close the ReShade overlay before moving again. During normal gameplay, numpad **+/-** adjusts radius by 0.10 m and numpad **8/2** moves the centre up/down by 0.05 m, live and saved, without opening any overlay. The 16:9 SA image remains centre-cropped to a square without stretching.

The effect supports rectangle, rounded rectangle, and ellipse masks, normalized source cropping, and adjustable edge feathering. It linearly samples SA when the image is near native screen size; at smaller sizes it uses four bilinear taps to reduce aliasing. GTA depth hides the plane where GTA geometry is closer. If ReShade does not report an available scene depth buffer, the plane is hidden rather than drawn through GTA objects. ReShade exposes `HostReversedZ` and `DepthBias` for calibration.

The current default Grove Street ground anchor, taken from the latest saved placement, is `X=88.110458, Y=-1922.158081, Z=20.698630, yaw=-141.490860°`. Existing legacy calibration files still load and migrate; the next save writes the v5 complete placement and tuning format. If no picture appears, first enable the `PortalSA` technique in ReShade and the GTA V-side portal checkbox in PortalDev.

`PortalVPlane.txt` v5 stores centre, yaw, radius/diameter, crop, edge tuning and the original ground Z. Lock In therefore survives later F9 placement: F9 changes only world position and heading, while the locked radius and centre-above-ground offset are retained. If the file does not exist, PortalV writes the complete built-in default on startup.

At runtime the visible circular plane presents its reverse face to GTA V's final rendered camera position around world Z, using the vector from the portal centre to the camera plus 180 degrees. This selects the non-mirrored horizontal texture orientation. It does not use the player or the camera's look direction. This is visual only: PortalDev continues to use the fixed saved calibration yaw for precise cross-game look-around mapping.

PortalV keeps the development spawn (`PortalVSpawn.txt`) separate from the F9 portal plane. Its built-in fallback is the user-confirmed 2026-10-10 GTA V Grove Street position `(85.336830, -1922.733000, 21.681070)`, heading `-134.562100°`. Press **F10** while GTA V is foreground to save the exact current player or occupied-vehicle position as the next development spawn. PortalV waits until the Story Mode player has remained available for two seconds and then automatically teleports to that spawn. It requests collision, loads the scene, probes the ground at several heights, freezes the entity during the move, and refuses the request if an Online session is detected. PortalDev also provides **TP 到 V 葛洛夫街** as a manual retry. The result and failure reason are shown in PortalDev and written to `PortalV.log`.

PortalV publishes the live draft or locked centre and yaw through `VState.v3`, so PortalDev uses the same portal basis for V→SA camera mapping while the ImGui controls are being dragged.

## Evidence and remaining checks

The x64 ASI and PortalDev build. `SAFramePublisherSmoke` verifies the SA→V three-slot channel; `D3D11D3D12BridgeSmoke` verifies a GPU copy into GTA V's display texture using a GPU fence. That test reads one 16×16 result back **only for verification**; the actual producer/consumer path has no full-frame CPU readback. The pinned ReShade FX compiler generated DXBC for both shader stages using the reference project's `ReShade.fxh`. The complete game path and depth calibration still require in-game acceptance.

Check that ReShade shows `PortalSA.fx` without errors, SA appears on the plane, a GTA wall/pedestrian occludes it as expected, moving the GTA camera keeps the plane stationary, and the image disappears within about 500 ms if SA capture stops. Then record both games' frame times, VRAM use, PortalDev's produced/overwritten/skipped counters, and ReShade's `PortalV SA received/skipped` log while both games run. Test 1080p and 720p with fixed scenes before selecting the next performance target.
